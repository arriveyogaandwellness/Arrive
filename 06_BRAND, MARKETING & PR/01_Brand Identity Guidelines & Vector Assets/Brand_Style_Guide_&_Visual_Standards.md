# Arrive Yoga — Brand Style Guide & Visual Identity Standards

## 1. Brand Essence & Voice
- **Archetype:** Sage + Creator + Sovereign Sanctuary.
- **Tone:** Grounded, poetic, trauma-aware, luxurious, deeply human, commanding yet gentle.
- **Avoid:** Performative toxic positivity, hyper-spiritual jargon, fitness competition energy.

---

## 2. Color Palette (Luxe Biophilic Aesthetic)

| Color Name | Hex Code | Usage | Meaning / Energy |
|:---|:---|:---|:---|
| **Deep Rainforest Emerald** | `#0F281E` | Primary Backgrounds / Dark Sections | Grounding, ancestral jungle canopy, stillness |
| **Warm Sand / Limestone** | `#F5F2EB` | Primary Light Canvas / Cards | Earth, clarity, breathable organic space |
| **Sage Mist** | `#7D9D8B` | Secondary Accents / Borders | Healing, somatic soothing, renewal |
| **Champagne Gold Leaf** | `#C5A880` | High-Ticket Accents / CTAs | Sacred luxury, warmth, honoring the student |
| **Obsidian Stone** | `#1A1A1A` | Core Typography / Deep Contrast | Volcanic black sand of Playa Hermosa |

---

## 3. Typography Hierarchy
- **Header Font:** *Cormorant Garamond* (Serif, Elegant, High-Fashion Luxury)
- **Sub-Header Font:** *Syne* (Modern, Confident, Architectural)
- **Body Text:** *Inter* or *Plus Jakarta Sans* (Clean, highly legible, accessible for all screens)
