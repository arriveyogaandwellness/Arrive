## 3. Standard Operating Protocols (SOP) & Best Practices

### File Naming Convention
To maintain clarity across all team members, name all working documents using the ISO format:  
`YYYY-MM-DD_[Department]_[DocumentName]_[Version/Initials].[ext]`  
*Example:* `2026-08-15_OPS_CostaRica_Flight_Manifest_v2_CK.csv`

### Document Version Control
- **Drafts:** Keep in the corresponding subfolder appended with `_DRAFT`.
- **Approved / Active:** Remove `_DRAFT` and save as final PDF or lock editing.
- **Archived:** Move outdated files to an `_Archive` folder within that section.
